## 📥 Get the app

- **Web app (works on any phone or computer):** [hustlearc.vercel.app](https://hustlearc.vercel.app)
- **Android APK:** [Download HustleArc.apk](https://github.com/Ahmadraza970/hustlearc/raw/refs/heads/main/HustleArc.apk)

> Android will ask you to allow installing from your browser/files app — that's normal for a direct APK install.

## ✨ What it does

- **Daily habit check-ins** for your Winter Arc — mark the day done and keep the arc unbroken
- **Ready-made preset packs** so you can start in one tap, including a study-focused pack for students
- **Runs fully offline** — no signal, no problem; your arc continues anywhere
- **No sign-up, no ads, no tracking** — open it and use it

## 🔒 Privacy, plainly

HustleArc stores everything **on your own device** (in the app/browser storage). There is no server copy of your habits, nothing is uploaded, and there is no account to leak. Uninstall or clear the app and the data is gone with it — because it was only ever yours.

## 🛠️ Tech

- Web app (HTML/CSS/JS) that installs like an app
- Android version packaged as a TWA (Trusted Web Activity)
